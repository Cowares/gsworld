# gsworld
This is my first rogue-like game

## VS Code 설정 (VS Code Setup)

이 프로젝트는 VS Code 워크스페이스 설정이 포함되어 있습니다.

### 권장 확장 프로그램 (Recommended Extensions)

VS Code에서 이 저장소를 열면 다음 확장 프로그램 설치를 권장합니다:

- **GitHub Copilot** (`github.copilot`) – AI 코드 자동완성
- **GitHub Copilot Chat** (`github.copilot-chat`) – AI 채팅 어시스턴트

> **참고:** GitHub Copilot은 무료 플랜(Free)과 유료 플랜(Pro/Business) 모두에서 VS Code 확장을 통해 사용할 수 있습니다.
> [GitHub Copilot 시작하기](https://github.com/features/copilot)

### 시작하기 (Getting Started)

1. [VS Code](https://code.visualstudio.com/)를 설치합니다.
2. 이 저장소를 클론합니다:
   ```bash
   git clone https://github.com/Cowares/gsworld.git
   cd gsworld
   ```
3. VS Code에서 폴더를 엽니다:

   ```bash
   code .
   ```
4. 권장 확장 프로그램 설치 알림이 표시되면 **Install**을 클릭합니다.
